# 📰 Fake News Detection System

A Machine Learning and NLP based web application that detects whether a news article is **Real** or **Fake**.

## 🚀 Features
- Fake & Real News Classification
- NLP Text Preprocessing
- TF-IDF Vectorization
- Logistic Regression & SVM Models
- Streamlit Web Application
- Performance Evaluation using:
  - Accuracy Comparison
  - ROC Curve
  - Precision-Recall Curve
  - Confusion Matrix

## 🛠️ Technologies Used:- Python, Scikit-learn, Pandas, NumPy, Streamlit, Matplotlib
