📰 Fake News Detection System

A Machine Learning based web application that detects whether a news article is Real News or Fake News using Natural Language Processing (NLP) techniques.

🚀 Project Overview

This project uses:

Machine Learning
Natural Language Processing (NLP)
TF-IDF Vectorization
Logistic Regression
Support Vector Machine (SVM)
Streamlit Web Application

to classify news articles as REAL or FAKE.
🎯 Features

✅ Detects fake and real news articles
✅ User-friendly Streamlit web interface
✅ Text preprocessing and cleaning
✅ TF-IDF feature extraction
✅ Logistic Regression & SVM models
✅ Accuracy comparison graphs
✅ ROC Curve

🛠️ Technologies Used
Python
Pandas
NumPy
Scikit-learn
Streamlit
Matplotlib
Seaborn
Pickle

🌐 Web Application

The application allows users to:

Enter news text
Click on Check News
Get prediction result:
✅ REAL NEWS
❌ FAKE NEWS
